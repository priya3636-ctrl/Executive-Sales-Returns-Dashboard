# Executive Sales & Returns Dashboard

## 📊 Project Overview
The Executive Sales & Returns Dashboard is an interactive business intelligence project developed using Microsoft Power BI. It helps analyze retail sales performance, product trends, sales channels, and returns through visualizations and key performance indicators (KPIs).

## 🎯 Project Objectives
- Monitor overall sales performance.
- Analyze order volume and average order value.
- Compare sales across states and product categories.
- Identify the top 10 products by sales.
- Track monthly sales trends.
- Understand product return reasons.
- Compare sales across different sales channels.

## ✨ Key Features
- KPI cards for Total Sales, Total Orders, Return Rate, and Average Order Value.
- Interactive state slicer for filtering the report.
- Sales by Product Category analysis.
- Sales by State analysis.
- Monthly Sales Trend.
- Top 10 Products by Sales.
- Returns by Reason.
- Sales by Channel comparison.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- DAX measures
- Data modeling
- Data visualization
- Interactive reporting
